# Screenshot capture checklist

After successfully building and running SCAPMS in VS Code, capture your own screenshots.
Use Windows Snipping Tool (`Win + Shift + S`) or your operating system's screenshot tool.
Save the images in this folder and insert them into the final assessment document.

Required views:
1. Main dashboard with the summary cards and Patient Records tab.
2. Patient registration dialog (show sample fictional data).
3. Appointment management tab with at least one appointment.
4. Search & Sort tab with the algorithm selectors visible.
5. Waiting Queue tab with one or more fictional patient IDs.
6. Reports dialog showing the generated report output.

Use fictional sample data only. Do not enter real patient or personal medical information.
